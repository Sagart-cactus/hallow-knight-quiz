# Hollow Knight — The Trial of Hallownest

A fan-made trivia quiz about Team Cherry's *Hollow Knight* (2017), built as a single, self-contained HTML page.

**▶ Play it live:** https://sagart-cactus.github.io/hallow-knight-quiz/

## What's inside
- **15 questions** spanning characters, areas, mechanics and lore — pitched at players (great for ages 10–15) who have actually wandered Hallownest.
- Answer options are **shuffled on every playthrough**.
- Each answer reveals a short **lore fact**.
- Your score maps you to a **soul of Hallownest** — from Zote the Mighty up to the Knight itself — each with custom mask artwork.
- Atmospheric design using official in-game backdrops, drifting spores and a glowing soul-meter.
- A cheeky **"Git gud!"** voice line when you miss one (browser text-to-speech — no audio files needed).

## Hosting
Static site, deployed automatically to **GitHub Pages** via [`.github/workflows/pages.yml`](.github/workflows/pages.yml) on every push to `main`.
